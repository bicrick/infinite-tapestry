# Security policy

## Reporting a vulnerability

Please report security issues privately, not in public issues or pull requests:

- GitHub: **Security → Report a vulnerability** on this repository (private vulnerability reporting), or
- email **support@infinitetapestry.app** with "Security" in the subject.

Include what you found, how to reproduce it, and the impact you expect. You'll get a reply as soon as possible, and
fixes are made on `main` and deployed from there.

## Scope

The code in this repository and the live site at https://infinitetapestry.app. Please don't run tests that degrade the
live site for other viewers (load tests, spam submissions) or access other users' data.
